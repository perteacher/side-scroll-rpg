# 메이플×그라나도 RPG 리부트 — 기획서 (v0 초안)

> 기존 M0~M12 코드는 폐기하고 처음부터 새로 짜되, 아래 설정은 그대로 유지.

## ① 캐릭터 / 유닛 목록

| 구분 | 설명 |
|---|---|
| 플레이어 파티 | 사이드스크롤 액션(메이플식) + 여러 캐릭터 영입해서 랭크업(그라나도 에스파다식) |
| 영입 캐릭터 이름 | 나무위키 "그라나도 에스파다" 캐릭터 문서 참고해서 이름 조금씩 변형 |
| 병영(barracks) | 영입한 캐릭터를 대기시키고 교체 투입하는 시스템 |
| 무기/스탠스 | 캐릭터별 무기 종류 + 스탠스(자세) 시스템, 스탠스별 스킬셋 분리 (STANCE_DATA) |
| 역할군 스킬 | ROLE_SKILLS_DATA로 역할별 스킬 정의 (근접/원거리/마법 등, 필요시 세분화) |
| MCC(동료 AI) | 대기 중이거나 파티에 있는 캐릭터가 자동으로 행동하는 AI 로직 |

*(기존에 정해둔 캐릭터 스탯 표가 있으면 그대로 가져와서 채워넣으면 됨 — 없으면 이번에 골격만 새로 잡음)*

## ② 성장 · 자원 시스템

- 경험치/레벨: 사이드스크롤 액션 기반 레벨링 (메이플식)
- 랭크 진행: 그라나도 에스파다식 랭크업 구조 (조건 충족 시 캐릭터 랭크 상승, 스크린샷처럼 GrandMaster Lv.10 형태 표기)
- 장비: 무기/방어구 장착, 스탠스와 연동
- 발사체 시스템: 원거리 공격류 캐릭터의 투사체 처리
- **사망 페널티: 없음 (확정)**

### 스탯 시스템 (그라나도 에스파다 UI 그대로 채용)

**기본 스탯 6종**: 힘 / 민첩 / 체력 / 기술 / 지능 / 감각

**공격능력**:
| 항목 | 설명 |
|---|---|
| 공격등급 | 명중 판정에 쓰이는 등급치 |
| 공격력 | 기본 공격 데미지 |
| 관통력 | 방어 무시 수치 |
| 크리티컬 / 크리티컬 대미지 | 치명타 확률 / 배율 |
| 명중률 | 회피 판정 대응 수치 |
| 방어력무시 | 상대 방어력을 뚫는 비율 |
| 공격속도 / 캐스팅속도 | 공격 딜레이 / 스킬 시전 속도 |
| 속성 공격력 | 물리 / 화염 / 빙한 / 전격 / 염력 5종 |

**추가 공격력 (종족/유형별 배율)**:
- 종족: 인간형 / 언데드형 / 악마형 / 무생물형 / 생물형
- 유형: PC / 몬스터, 각각 중갑·경갑·연갑 방어구 타입별 배율

**방어능력**:
| 항목 | 설명 |
|---|---|
| 방어등급 / 방어력 | 물리 방어 |
| 상태이상저항 | 기절/속박 등 CC 저항 |
| 면역도 | 상태이상 면역 수치 |
| 속성 저항력 | 화염/빙한/전격/염력 개별 저항 |

캐릭터 정보창은 원본처럼 **장비 / 스탠스,스킬 / 장비교체등록** 탭 구조로.

### 캐릭터 이름 풀 (나무위키 그라나도 에스파다 캐릭터 목록 참고, 변형해서 사용)

원본 이름을 그대로 안 쓰고 살짝 바꿔서 사용. 예시 변형안 (초기 로스터 후보):
- 파이터 → 파이온 / 위자드 → 위자르 / 스카우트 → 스카웃 / 머스킷티어 → 머스킷샤 / 워록 → 워라크
- 끌로드 → 클로데 / 잇지 → 잇쥬 / 라미로 → 라미로프 / 아델리나 → 아델린 / 에밀리아 → 에밀레아
- 로르크 → 로르켄 / 까뜨린느 → 까뜨렌느 / 로미나 → 로미나스 / 리사 → 리사엘
- 발레리아 → 발레리안 / 스티아 → 스티아나 (스크린샷 캐릭터, 그대로 써도 무방) / 베레타 → 베레티아

전체 리스트는 위키에 200개 넘게 있으니, 초기 로스터(예: 10~15명)만 우선 확정하고 나머지는 이후 콘텐츠 추가 시 순차 반영.

## ③ 적 AI 행동

- 에피소드 구조: 그라나도 에스파다처럼 스테이지/에피소드 단위 진행
- 몬스터 스폰/패턴: **미정 — 우선 스폰 없이 구현하고 플레이하면서 패턴을 정함**

## ④ 조작 체계

- 이동: 키보드 방향키(상하좌우)
- 공격: 키보드
- 단축키: 아이템창 / 유닛 스탯 / 스킬 / 퀘스트 등 각각 지정
- 마우스: NPC 상호작용, 아이템 착용 등 UI성 조작 전용 (이동/전투엔 마우스 미사용)

## ⑤ 화면 구성 (UI) — 그라나도 에스파다 참고 스크린샷 기반

**하단 바 (핵심)**:
- 파티원 슬롯(최대 3명 노출): 각 슬롯에 초상화 + 이름/레벨 + HP바(숫자 병기) + MP바(숫자 병기)
- 각 파티원 슬롯 아래 스킬 단축바: QWE / ASD / ZXC 형태의 3x3 키 배치, 아이콘 형태
- 파티원 슬롯 옆에 골드 등 재화 아이콘 표시

**상단**:
- 좌측: 메뉴/기능 아이콘 바 (인벤토리, 지도, 설정 등 진입점)
- 상단 중앙: 타겟(적) 이름 + 체력바 (전투 중 표시)
- 우측: 미니맵 (원형)

**캐릭터 정보 창 (Alt+E 형태의 토글 창)**:
- 탭 구성: 장비 / 스탠스,스킬 / 장비교체등록
- 힘·민첩·체력·기술·지능·감각 6대 스탯 + 공격능력/추가공격력/방어능력 표 (위 스탯 시스템 참고)
- 장비 슬롯 그리드, 저장/도움말/적용/프리셋 버튼

**기타**:
- 채팅창: 전체/일반/스퀴드/당/귓속말/NPC/커스텀/시스템 탭
- 인벤토리 창, 퀘스트 창은 별도 단축키로 토글
- 스킬 쿨다운 UI는 **보류** — 이번 구현엔 미포함
- 병영(대기 캐릭터 교체) 화면

## ⑥ 완료 기준 체크리스트 (초안 — 승인 시 확정)

- [ ] 방향키로 캐릭터가 좌우 이동 + 점프(필요시)한다
- [ ] 키보드 공격 입력 시 현재 스탠스에 맞는 모션/판정이 나간다
- [ ] 단축키로 인벤토리/스탯/스킬/퀘스트 창이 각각 열고 닫힌다
- [ ] NPC를 마우스로 클릭하면 상호작용(대화/거래 등)이 열린다
- [ ] 영입 캐릭터를 병영에서 파티로 교체 투입할 수 있다
- [ ] 스탠스를 바꾸면 사용 가능한 스킬셋이 바뀐다
- [ ] 원거리 캐릭터의 발사체가 정상적으로 몹에게 명중 판정된다
- [ ] 에피소드(스테이지) 클리어 조건 달성 시 다음 에피소드로 넘어간다
- [ ] 브라우저 콘솔 에러 0건

## 기술 기본값

- Vanilla JS + Canvas 2D (기존과 동일)
- GitHub Pages 배포 (perteacher 계정)
- 데이터-엔진 분리 아키텍처 유지: STANCE_DATA / ROLE_SKILLS_DATA 등은 별도 데이터 객체로, 엔진 로직과 분리
- 버프는 스탯별 맵 구조로 관리

## 성능 상한 (Canvas 2D 기준)

- 목표 프레임: 60fps
- 최악 장면 정의: (예: 파티원 최대치 + 화면 내 몹 다수 + 발사체 다수 동시 — 구체 수치는 승인 시 확정)
- 화면 내 동시 렌더 오브젝트 상한 지정 필요 (스프라이트 개수 기준)
