# 메이플×그라나도 RPG 리부트 — 기획서

> v3 (2026-09-14). v0 초안으로 시작해 구현하면서 갱신했다.
> 초안 원문은 git 이력(커밋 56605c7의 docs/plan.md)에서 볼 수 있다.

사이드스크롤 액션(메이플식)에 캐릭터 영입·스탠스 성장(그라나도 에스파다식)을 얹은 브라우저 RPG.
Vanilla JS + Canvas 2D만 쓰고 빌드 도구나 외부 라이브러리가 없다.

## ② 성장 · 자원

### 캐릭터 레벨
기본 **1~100** → **베테랑 1~10** → **익스퍼트 1~10** → **마스터 1~10** (내부 연속 레벨 1~130).
승급 구간은 요구 경험치 배율이 크다 — 베테랑 1업에 약 126만, 마스터 구간은 5천만 단위.

### 스탠스 숙련도
스탠스별로 레벨·경험치·스킬포인트를 따로 관리한다. 레벨업마다 포인트 1개를 받아
스킬을 습득(최대 Lv.5)하고, 스킬 레벨 1당 위력 +15%.

### 가문 특성 (그라나도 에스파다 원본 시스템)
캐릭터가 레벨업하면 가문 경험치가 쌓이고 **가문 레벨 1당 특성 포인트 1개**를 받는다.
3단계 스킬트리이고 상위 단계는 **윗 단계 투자량 + 가문 레벨** 두 조건을 모두 만족해야 열린다.
포인트는 언제든 회수·재분배할 수 있으며 효과는 **전 캐릭터에 적용**된다.

- 1단계: 전투 훈련(공격력) / 방어 훈련(방어력) / 체력 단련(최대 HP)
- 2단계(가문 Lv.10 + 1단계 10p): 공격속도 / 이동속도 / 명중률
- 3단계(가문 Lv.25 + 2단계 15p): 관통(방어 무시) / 가문의 비전(공격력 증폭)

> 원본에서 확인된 것은 **구조**(레벨당 1포인트, 트리 조건, 자유 재분배, 가문 전체 적용)와
> **항목 종류**까지다. 1포인트당 수치·항목 상한·최대 가문 레벨은 공개 자료에 없어
> 자체 밸런싱했다. 근거와 미확인 범위는 `js/data/family.js` 주석에 적어뒀다.

### 장비
무기 세트 3벌(각 주/보조) + 갑옷/투구/신발. 생성 시 스탠스에 맞는 무기와 등급에 맞는 방어구를 착용한 채 시작한다.

**무기 세트(장비교체등록)** — 그라나도 에스파다의 상징 시스템. 무기 조합을 3벌까지 등록해두고
전투 중 `1`/`2`/`3` 키로 통째로 갈아낀다. 세트마다 무기가 다르면 스탠스·사거리·스킬셋이 전부 바뀌므로
교체 자체가 전투 운영 수단이다(재사용 대기 2.5초, 교체 직후 0.35초 공격 경직).
생성 시 주 스탠스 무기는 세트1, 보조 스탠스 무기는 세트2에 들어간다. 빈 세트로 바꾸면 맨손이 된다.
- 무기는 그 스탠스를 가진 캐릭터만, 방어구는 자기 등급(중갑/경갑/연갑)만 장착 가능
- 티어 1~5, 총 95종. 상위 티어는 몹 드랍(존 레벨 기준 7%)과 제작으로 얻는다
- **강화** 최대 +10, 1단계당 +12%. 실패해도 파괴되지 않고 +4 이상에서만 한 단계 하락
- **인챈트** 7종(공격/방어/크리티컬/HP) 중 랜덤 부여, 재시도 시 덮어쓰기
- 인벤토리(I)에서 보관 장비를 바로 장착·판매할 수 있고, 지금 낀 것 대비 증감을 `▲+12` / `▼-5`로 보여준다

### 경제
잡템 15종이 몹에서 드랍된다. 상점에서 판매·구매·제작·강화를 하고, 제작품은 퀘스트 납품에 쓴다.
경험치 카드(일반/베테랑/익스퍼트/마스터)와 스탠스 수련서는 퀘스트 보상으로만 나온다.
승급 카드는 해당 등급에 도달한 캐릭터만 사용할 수 있다.

### 사망
사망 페널티 없음. HP 0이면 전투 불능(쓰러짐)이 되고 자동 회복이 멈춘다.
마을에 들어가면 회복되고, 전멸하면 가장 가까운 마을로 돌아간다.

### 스탯
기본 6종(힘/민첩/체력/기술/지능/감각)에 공격능력·방어능력 표를 그라나도 에스파다 UI 구조로 노출한다.
전투 계산에 실제로 쓰이는 값은 공격력·방어력·크리티컬·명중/회피·관통이고,
나머지 항목은 표시용이다.

### 고유 특성 · 전용기
영입 캐릭터 35명과 기본 클래스 5종에게 **각자 다른 패시브 1개와 전용기 1개**를 줬다.
스탠스 스킬은 역할군 공용이라 누구를 데려가도 전투가 비슷했던 문제를 메우는 장치다.

- **패시브 12종**: 철벽 / 광전사 / 결투가 / 쾌속 / 명사수 / 비전 / 흡혈 / 수호 / 추적자 / 전술가 / 불굴 / 처형자.
  공격력·방어력·치명타·명중·이동속도·흡혈 등을 조정하며, 가문 특성·버프와 같은 형태로 합산된다(`unit.bonus`)
- **전용기**: 캐릭터 레벨 **10**에 개방. `R`키(조작 캐릭터) 또는 자동전투가 사용한다.
  7가지 유형 — 단일 극딜 / 연타 / 범위 / 연쇄 / 흡혈 / 파티 강화(지속 12초) / 파티 회복
- 파티 강화·회복형은 대상이 없어도 쓸 수 있어서, 딜러만 모을지 지원가를 낄지가 실제 선택이 된다

## ③ 적 AI

- **선공/비선공** 구분. 선공은 시야에 들어오면 덤비고, 비선공은 맞아야 반격한다(맞으면 어그로 2배)
- 전투 중이 아니면 스폰 지점 주변을 배회한다
- 처치 후 12초 뒤 리스폰(보스는 60초)
- **보스 8종**: 예고 후 발동하는 패턴 4가지 — 돌진 / 강타(범위) / 소환 / 탄막.
  HP 절반 밑에서 광폭화(공격력 +35%, 패턴 주기 단축). 예고 중 바닥·진로에 경고 표시

## ④ 조작

|---|---|
| ← → | 이동 |
| ↑ | 점프 / 포탈 진입 |

- **목표 트래커**: 화면 우측에 진행 중인 시나리오·영입·의뢰 목표와 탑 진행 상황을 상시 표시(설정에서 끌 수 있음)
- **설정 창(O)**: 음량 슬라이더, 자동 물약 on/off와 HP·MP 기준선, 목표 표시·데미지 숫자 토글,

- **연출**: 데미지 숫자(치명타·MISS 구분), 베기 궤적, 시전 마법진, 범위 폭발, 피격 점멸, 레벨업 표시,
  획득 아이템이 몹 자리에서 떠오름(티어 색)

- **사운드**: 음원 파일 없이 Web Audio API로 전부 합성한다. 타격·치명타·MISS·피격·처치·스킬(속성별 음색)·

  (마을 / 사냥터 / 탑 / 보스)을 8분음표로 예약 재생한다. 🔊 버튼으로 100% → 50% → 음소거 순환(설정 저장)

## ⑥ 월드

마을 6곳 + 사냥터 13곳 + 엔드게임 존 1곳이 갈래로 이어진 그래프. 일직선이 아니라 마을마다 사냥터 2곳으로 갈라지고
사냥터끼리 샛길로 연결된다. 존마다 점프로 오르는 2층 발판이 있고 몹과 NPC 일부가 2층에 있다.
이동은 워프(↑ 입력) 또는 텔레포트 창(레벨순 목록).

## ⑧ 파티 시너지

파티 구성에 따라 전원이 버프를 받는다 — 균형 잡힌 진형(3역할 각 1명 이상), 전열 결속(근접 2),
일제 사격(원거리 2), 마력 공명(마법 2), 삼인 완편(3명), 역전의 용사(전원 Lv.10+).

## ⑨ 엔드게임 — 심연의 탑

만렙까지는 사냥터가 채우고, 그 뒤로는 이 탑이 목표가 된다.

- 상단 🗼 버튼(또는 `G`)으로 입장. **Lv.20 이상 캐릭터가 1명 이상** 필요
- 층의 적을 전부 쓰러뜨리면 1.8초 뒤 다음 층이 열린다. 탑 안에서는 몹이 리스폰되지 않는다
- 몹은 층당 HP ×1.28 / 공격 ×1.22 / 방어 ×1.24 / 경험치 ×1.30으로 불어난다 (30층이면 1층의 1,000배 이상)
- **5층마다 보스**. 보스는 층에 맞춰 수치가 계산된 전용 패턴 4종(강타·돌진·탄막·소환)을 인스턴스로 들고 나온다
- 층 클리어마다 골드·경험치, 보스 층마다 경험치 카드 + 스탠스 수련서.
  층대에 따라 일반 → 베테랑(15층~) → 익스퍼트(30층~) → 마스터(45층~) 카드로 올라간다
- 전멸하면 밀려나지만 **최고 기록은 남는다**. 5층 단위 체크포인트부터 재도전할 수 있다
- 도전 자체는 저장되지 않는다(최고 기록만 저장). 탑에서 저장한 게임은 가까운 마을에서 재개된다

## 기술

- Vanilla JS + Canvas 2D, 빌드 없음. 로컬 서버로 열기만 하면 실행
- GitHub Pages 배포 (perteacher 계정)
- 데이터-엔진 분리: `js/data`를 고치면 콘텐츠가 바뀌고 `js/engine`이 그 데이터를 해석한다
- localStorage 자동 저장(10초 주기 + 존 이동/종료 시)

## 성능

- 목표 60fps. 실측 **1.14ms/frame** (update 0.42 + render 0.72, 예산 16.6ms)
- 측정 장면: 최다 스폰 사냥터 '시간이 멈춘 회랑'(몹 25, 이펙트 14) / 탑 28층(잡몹 12)
- 목표 트래커는 매 프레임이 아니라 250ms마다 갱신하고, 내용이 바뀔 때만 DOM을 쓴다(0.003ms)
- 이펙트는 240개에서 오래된 것부터 제거

## 남은 것

- 채팅 탭은 8개가 있지만 실제로 쓰이는 건 시스템/NPC/파티 3개뿐
- 자동 물약은 HP/MP 물약 1종씩만 쓴다(상위 물약이 없음)
- 장비 비교는 현재 세트의 주무기 기준이라, 보조무기에 낄 때의 증감은 따로 보여주지 않는다
- 가문 특성 수치는 원본 확인이 안 돼 자체 밸런싱 상태.
  캐릭터 고유 특성·전용기도 이름만 원작 캐릭터에서 따왔고 성능은 전부 자체 설계다
- 전용기 MP 소모가 고정값이라 고레벨에서는 사실상 쿨다운만 제약으로 남는다
- 심연의 탑은 층 구조가 한 종류다(발판 배치가 층마다 같다)
- 온라인/멀티플레이 없음
