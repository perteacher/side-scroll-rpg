# 메이플×그라나도 RPG 리부트

사이드스크롤 액션(메이플식)과 캐릭터 영입·스탠스 성장(그라나도 에스파다식)을 합친 브라우저 RPG.
Vanilla JS + Canvas 2D로만 구현했고 빌드 도구나 외부 라이브러리를 쓰지 않는다.

## 실행

로컬 서버로 띄운다(파일을 직접 열면 일부 브라우저에서 스크립트가 막힌다).

```bash
python -m http.server 8421
```

`http://localhost:8421` 접속.

## 조작

| 키 | 동작 |
|---|---|
| ← → | 이동 |
| ↑ | 점프 / 포탈 진입 |
| ↓ | 아래층으로 내려가기 |
| Space | 기본 공격 |
| QWE / ASD / ZXC | 1·2·3번 캐릭터 스킬 |
| V | 스탠스 전환 |
| Tab | 리더 전환 |
| I / Alt+E / J / B / T | 인벤토리 / 캐릭터 정보 / 퀘스트 / 병영 / 텔레포트 |
| 마우스 | NPC·몹 클릭, UI 조작 |

## 구조

데이터와 엔진을 분리했다. `js/data`를 고치면 콘텐츠가 바뀌고, `js/engine`은 그 데이터를 해석한다.

```
js/data/     스탠스, 역할군 스킬, 클래스, 영입 캐릭터, 월드(존/몹/워프/발판),
             시나리오, 영입 퀘스트, 아이템·장비·제작, 보스 패턴, 파티 시너지
js/engine/   입력, 스탯 계산, 엔티티, AI, 파티/병영, 존, 퀘스트, 시나리오,
             세이브, 이펙트, 렌더러, UI, 게임 루프
```

## 콘텐츠

- 마을 5곳과 사냥터 10곳이 갈래로 이어진 맵. 각 존에 점프로 오르는 2층이 있다.
- 기본 클래스 5종(최대 3명 생성) + 마을 퀘스트로 영입하는 캐릭터 35명.
- 스탠스별 숙련도와 스킬 트리(단일기/범위기), 장비 5부위 + 강화/인챈트.
- 시나리오 챕터 1~5, 다단계 영입 퀘스트, 티어별 보스 5종.
- 자동전투 3모드(정지/킵/홀드).

자세한 기획 배경은 [docs/plan.md](docs/plan.md) 참고.
