# 메이플×그라나도 RPG 리부트

사이드스크롤 액션(메이플식)과 캐릭터 영입·스탠스 성장(그라나도 에스파다식)을 합친 브라우저 RPG.
Vanilla JS + Canvas 2D로만 구현했고 빌드 도구나 외부 라이브러리를 쓰지 않는다.

## 실행

### 1. 웹으로 바로 하기
<https://perteacher.github.io/side-scroll-rpg/>

### 2. 데스크톱 실행 파일 (Windows)
`dist/SideScrollRPG-1.0.0.exe` 를 더블클릭한다. 설치가 필요 없는 단일 파일이고,
세이브는 실행한 PC에 저장된다. F11 전체화면, F5 새로고침. 창 크기를 바꾸면 화면이 같이 커지고, 설정(O)에서 해상도를 고를 수 있다.

직접 빌드하려면:

```bash
npm install
npm run build:win
```

### 3. 로컬 서버로 열기
```bash
python -m http.server 8421
```
`http://localhost:8421` 접속. (`index.html`을 직접 열면 일부 브라우저에서 스크립트가 막힌다)

| R | 조작 캐릭터의 전용기 |

| 공중에서 ↑ | 플래시 점프 |

| F11 | 전체 화면 |
| 마우스 | NPC·몹 클릭, UI 조작 |

## 구조

데이터와 엔진을 분리했다. `js/data`를 고치면 콘텐츠가 바뀌고, `js/engine`은 그 데이터를 해석한다.

```
js/data/     도트 스프라이트(아이템·캐릭터·몬스터), 스탠스, 역할군 스킬, 클래스, 영입 캐릭터, 월드(존/몹/워프/발판),
             시나리오, 영입 퀘스트, 일반 퀘스트, 아이템·장비·제작,
             보스 패턴, 파티 시너지, 가문 특성, 캐릭터 고유 특성·전용기, 심연의 탑
js/engine/   입력, 설정·기록, 스탯 계산, 엔티티, AI, 파티/병영, 존, 퀘스트, 시나리오,
             가문, 심연의 탑, 세이브, 이펙트, 사운드, 렌더러, UI, 게임 루프

electron-main.js     데스크톱 실행용 진입점 (게임 파일은 웹판과 동일)
electron-preload.js  설정의 해상도 선택을 창 크기로 넘기는 통로
```

## 콘텐츠

- 마을 6곳과 사냥터 13곳이 갈래로 이어진 맵. 각 존에 점프로 오르는 2층이 있다.
- 기본 클래스 5종(최대 3명 생성) + 마을 퀘스트로 영입하는 캐릭터 35명.
- 캐릭터 40명 전원이 **고유 패시브 1개 + 전용기 1개**를 갖는다(전용기는 Lv.10 개방, R키).
  단일 극딜·연타·범위·연쇄·흡혈·파티 강화·파티 회복 7유형이라 파티 구성이 전투에 드러난다.
- **무기 세트 3벌**을 등록해두고 전투 중 1/2/3 키로 교체한다. 세트마다 스탠스가 바뀐다.
- 스탠스별 숙련도와 스킬 트리(단일기/범위기), 장비 5부위.
- 상태이상 7종(기절·빙결·냉기·출혈·화상·감전·방어 붕괴). 스킬·전용기·속성 기본 공격이 걸고, 보스 패턴은 파티에 기절·화상을 건다.
- 해상도: 창 크기에 맞춰 화면 전체가 커진다(글자·체력바는 선명하게). 설정에서 고정 해상도·전체 화면 선택.
- 창 여는 버튼은 좌상단 `MENU` 하나로 접혀 있다. 목록에 마우스를 올리면 아이템 설명이 뜬다.
- 고급 HP/MP 물약과 만병통치약(상태이상 해제). 자동 물약은 많이 비었을 때 고급 물약부터 쓴다.
- 첫 실행에는 프롤로그 "영웅의 기억" — 전성기 3인방으로 마왕과 싸워보고 나서 내 캐릭터를 만든다(Esc로 건너뛰기).
- 초반 20레벨까지는 레벨업마다 한 단계씩 더 오르고, 정해진 레벨마다 보상 상자와 다음 할 일 안내가 나온다.
- 처음 보는 몬스터는 확정 드랍, 3티어 이상 장비가 뜨면 화면이 번쩍인다. 영입 가능한 35명은 도감에서 실루엣으로 미리 본다.
- 메이플스토리식 시스템: 플래시 점프·로프·바닥 전리품 줍기, 장비 강화(파괴·찬스 타임·파괴 방지)와
  잠재능력(큐브 3종, 레어~레전드리), 몬스터 컬렉션과 링크 스킬. 동료도 로프를 타고 플래시 점프로 따라붙는다.
- 캐릭터 단계(일반/베테랑/익스퍼트/마스터)마다 같은 무기로 쓰는 상위 스탠스를 하나씩 배운다(상위 스탠스 20종).
- 스탠스 레벨이 곧 스탯 성장이다. 무기 계열별 성향대로 힘·민첩·지능 등이 오르고 모든 스탠스가 합산된다.
- 시나리오 챕터 1~5, 다단계 영입 퀘스트, 마을 게시판 일반 퀘스트, 보스 8종.
- 캐릭터 레벨 1~100 → 베테랑/익스퍼트/마스터 각 1~10. 가문 특성 트리(전 캐릭터 공용).
- **엔드게임 — 심연의 탑**: 층마다 강해지는 무한 던전. 5층마다 보스, 최고 기록과 체크포인트.
- 자동전투 3모드(정지/킵/홀드)와 자동 물약(HP/MP 기준선 조절 가능).
- 화면 우측 목표 트래커, 몹 레벨·위험도 색, 장비 비교(▲/▼), 획득 아이템 표시.
- 설정 창(O)에서 음량·표시 옵션·조작 안내와 플레이 기록(처치 수, 플레이 시간, 누적 골드)을 본다.
- 창은 겹쳐 뜨지 않는다. 빈 자리를 찾아 배치하고, 제목 표시줄을 끌어 옮기면 그 자리를 기억한다.
- 사운드는 음원 파일 없이 Web Audio로 합성한다(효과음 + 존별 BGM 4종, 🔊 버튼으로 음량 조절).
- 그래픽은 전부 도트다. 이미지 파일 없이 픽셀 격자를 코드로 정의해 아이템 126종·캐릭터 40명·몬스터 34종과
  배경(하늘·구름·산·나무·집·지면·발판)·이펙트까지 그린다.

자세한 기획 배경은 [docs/plan.md](docs/plan.md) 참고.
